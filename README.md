# avelec-fiches

Fiches visuelles publiées sur la page Facebook d'Ave'Lec (électricien, Saint-Ghislain).
Dépôt public : uniquement des fiches de conseils, jamais de données clients.

- `outil/` : modèle et script de rendu des fiches
- `fiches/AAAA-MM/` : fiches (PNG) et leur contenu (JSON)
- `publies.md` : journal des fiches déjà publiées
